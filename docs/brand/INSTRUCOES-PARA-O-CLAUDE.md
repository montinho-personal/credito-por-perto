# Vetores — Crédito por Perto

Todos os logos estão em SVG vetorial real e podem ser ampliados sem perda de qualidade.
As letras foram convertidas em curvas, portanto não dependem da instalação da fonte Inter.

## Arquivos

- `credito-por-perto-logo-horizontal.svg` — versão principal para o cabeçalho.
- `credito-por-perto-logo-principal.svg` — composição maior/empilhada.
- `credito-por-perto-wordmark.svg` — somente o nome.
- `credito-por-perto-icon.svg` — símbolo isolado.
- `credito-por-perto-favicon.svg` — favicon.
- `credito-por-perto-logo-horizontal-fundo-escuro.svg` — para fundo azul, preto ou escuro.
- `credito-por-perto-logo-monocromatico.svg` — versão de uma cor.
- `credito-por-perto-brand.css` — variáveis de cor.

## Cores

- Azul confiança: `#0D3B66`
- Dourado proximidade: `#E0A21A`
- Grafite: `#1A1A1A`
- Cinza claro: `#F4F4F4`
- Branco: `#FFFFFF`

## Instrução para o Claude Code

Copie a pasta para `public/brand/` e use:

```html
<img
  src="/brand/credito-por-perto-logo-horizontal.svg"
  alt="Crédito por Perto"
  width="360"
  height="88"
/>
```

No cabeçalho responsivo, use o logo horizontal em telas maiores e o ícone isolado
em espaços muito pequenos. Não aplique sombras, gradientes, contornos ou distorções.
Mantenha uma área livre ao redor do símbolo equivalente a aproximadamente 20% da altura do ícone.
