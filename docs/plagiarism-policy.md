# Política de plágio e direitos autorais

## Pesquisa de concorrentes sem cópia

Concorrentes servem para: mapear a SERP, entender intenções, descobrir dúvidas
recorrentes, identificar lacunas e informações desatualizadas, comparar
experiência. **Nunca copiar** de concorrentes: títulos, sequência de
subtítulos, estrutura completa, introduções, parágrafos, analogias, exemplos,
FAQs, tabelas, metodologias, ilustrações, imagens, infográficos, calculadoras,
identidade, descrições, código, nem dados sem conferir a fonte original.
Mapeada uma lacuna, a pesquisa continua em **fontes primárias** — concorrente
não é fonte final de afirmação financeira quando existe fonte oficial.

## Citação e reprodução

- Explicações com palavras próprias; a fonte confirma fatos, não empresta redação;
- Tabelas: recriar a partir de dados primários, citando origem — nunca copiar
  tabela completa;
- Imagens/infográficos: apenas próprios, licenciados ou domínio público
  (ver `docs/image-licensing-policy.md`); nunca remover marca d'água;
- Citações literais: só quando necessárias, entre aspas, com autor e fonte,
  no trecho mínimo. Atribuir a fonte **não** autoriza reprodução extensa;
- Casos duvidosos → revisão jurídica antes de publicar;
- **Canonical não é mecanismo de autorização**: página copiada continua
  inadequada mesmo com canonical apontando para a origem.

## Verificação externa antes de publicar

1. Separar o conteúdo editorial (sem componentes compartilhados/avisos);
2. Selecionar amostras representativas de frases longas;
3. Buscar correspondências exatas em ferramentas de busca permitidas
   (busca manual com aspas; **não** fazer scraping não autorizado do Google);
4. Com integração autorizada, usar API legítima de verificação de plágio;
5. Registrar o resultado; reescrever passagens suspeitas a partir das fontes
   primárias; repetir a verificação;
6. Dúvida substancial → manter como rascunho.

Ausência de correspondência não é prova absoluta de originalidade; a
verificação automatizada é filtro, não substitui revisão editorial.
